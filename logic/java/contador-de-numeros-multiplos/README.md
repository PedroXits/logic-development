## Enunciado

Escreva um programa que leia um número inteiro n e conte quantos números entre 1 e n são múltiplos de 3 e 5. Por exemplo, se a entrada for 15, os números múltiplos de 3 e 5 entre 1 e 15 são: 3, 5, 6, 9, 10, 12 e 15. No caso, a saída deve ser 7.

Entrada:
15

Saída:
7
