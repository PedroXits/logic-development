## Enunciado

Leia dois números inteiros A e B. O seu objetivo é verificar se A é maior que B e imprimir 'A é maior' se for verdade. Caso contrário, imprima 'B é maior' se B for maior ou 'A e B são iguais' se ambos forem iguais.

Exemplo:
Entrada:
10
5
Saída:
A é maior
