## Enunciado

Escreva um programa que encontre o maior fatorial de um número inteiro não negativo que seja menor do que um número fornecido. O fatorial de um número n é o produto de todos os inteiros positivos até n. Por exemplo, o fatorial de 5 é 5! = 5 x 4 x 3 x 2 x 1 = 120. Você deve ler um número inteiro N e imprimir o maior fatorial que é menor do que N. Se não houver nenhum fatorial abaixo de N (ou seja, se N for menor ou igual a 1), o programa deve imprimir 0.

Exemplo:
Entrada:
10
Saída:
6
