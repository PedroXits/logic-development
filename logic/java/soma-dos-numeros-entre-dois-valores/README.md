## Enunciado

Dado dois números inteiros, você deve calcular a soma de todos os números inteiros que estão estritamente entre esses dois valores (excluindo os limites). Caso não haja números entre os limites, a soma deve ser zero.

Exemplo:
Entrada:
4
10
Saída:
30

Nesse exemplo, os números entre 4 e 10 são 5, 6, 7, 8 e 9, cuja soma é 30.
